# Offload — Handoff

In the private repository this file is the running session log: what is running on the machine, what just
finished, and what the next agent session should do first. It is left out of the public snapshot because
it is about one person's machine and day-to-day decisions rather than the project.

What it is for, and how it keeps work going across agent sessions, is described in
[`BUILDING-WITH-AI.md`](BUILDING-WITH-AI.md). Where the project is going is in [`PLAN.md`](PLAN.md), and
the measured results are in `bench/results/summary.md`.
